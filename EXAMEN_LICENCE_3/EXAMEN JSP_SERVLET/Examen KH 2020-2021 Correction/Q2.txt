Pour rediriger un utilisateur vers la page "accueil.jsp" après une action réussie dans une application web Java (par exemple, utilisant des servlets), vous pouvez utiliser la méthode `sendRedirect()` de l'objet `HttpServletResponse`. Voici un exemple simple de code qui montre comment faire cela dans un servlet :

```java
import java.io.IOException;
import javax.servlet.ServletException;
import javax.servlet.annotation.WebServlet;
import javax.servlet.http.HttpServlet;
import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;

@WebServlet("/monAction")
public class MonActionServlet extends HttpServlet {
    protected void doPost(HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException {
        // Logique de votre action ici
        boolean actionReussie = true; // Remplacez par la condition de succès de votre action

        if (actionReussie) {
            // Redirige vers la page d'accueil
            response.sendRedirect("accueil.jsp");
        } else {
            // Gérer le cas où l'action a échoué, par exemple, afficher un message d'erreur
            request.setAttribute("erreur", "L'action a échoué.");
            request.getRequestDispatcher("erreur.jsp").forward(request, response);
        }
    }
}
```

### Explication :

1. **Importations** : Vous devez importer les classes nécessaires pour la gestion des servlets.
2. **Servlet** : Le servlet est annoté avec `@WebServlet("/monAction")`, ce qui signifie qu'il va traiter les requêtes envoyées à l'URL "/monAction".
3. **Méthode `doPost`** : Cette méthode est appelée lorsque le servlet reçoit une requête HTTP POST.
4. **Action réussie** : Vous vérifiez si l'action a réussi (dans cet exemple, `actionReussie` est une variable fictive, vous devez la remplacer par la logique réelle).
5. **Redirection** : Si l'action est réussie, la méthode `sendRedirect("accueil.jsp")` est utilisée pour rediriger l'utilisateur vers "accueil.jsp".
6. **Gestion des erreurs** : Si l'action échoue, vous pouvez rediriger l'utilisateur vers une page d'erreur ou renvoyer un message d'erreur.

### Remarques :

- Assurez-vous que "accueil.jsp" est accessible à partir de la racine de votre contexte web.
- La redirection avec `sendRedirect` envoie une réponse HTTP 302, ce qui indique au navigateur qu'il doit effectuer une nouvelle requête vers l'URL spécifiée.
- Si vous voulez conserver les attributs de requête, utilisez `RequestDispatcher` pour faire un transfert (`forward`) au lieu de rediriger.
