### **Réponses à l'examen JSP-Servlet**

#### **Q1 (Scriptlet pour récupérer le choix du journal)**  
Dans la page `infos.jsp`, utilisez :
```jsp
<%
    String choix = request.getParameter("journal");
%>
```

- **Explication** : La méthode `request.getParameter()` récupère la valeur associée au champ `journal` du formulaire.

---

#### **Q2 (Utilisation de EL pour récupérer le choix)**  
Dans la page `infos.jsp`, utilisez :
```jsp
${param.journal}
```

- **Explication** : `${param.journal}` est une expression EL qui récupère directement la valeur envoyée via le champ `journal`.

---

#### **Q3 (Enregistrer le choix dans la session avec EL)**  
Ajoutez ce code dans votre page JSP :
```jsp
<c:set var="choix" value="${param.journal}" scope="session" />
```

- **Explication** : La balise JSTL `<c:set>` permet d’enregistrer une valeur dans un scope donné, ici dans la session.

---

#### **Q4 (Rediriger vers la page correspondant au choix avec Scriptlet et actions JSP)**  
Dans la page `infos.jsp`, ajoutez :
```jsp
<%
    String choix = request.getParameter("journal");
    if ("lequot".equals(choix)) {
        response.sendRedirect("leQuotidien.jsp");
    } else if ("walf".equals(choix)) {
        response.sendRedirect("walfadjri.jsp");
    }
%>
```

- **Explication** : 
  - La méthode `response.sendRedirect()` redirige l’utilisateur vers une autre page.
  - Les valeurs des options du formulaire (`lequot`, `walf`) déterminent la redirection.

---

#### **Q5 (Redirection avec JSTL et EL)**  
Utilisez le code suivant dans la page JSP :
```jsp
<c:choose>
    <c:when test="${param.journal == 'lequot'}">
        <c:redirect url="leQuotidien.jsp" />
    </c:when>
    <c:when test="${param.journal == 'walf'}">
        <c:redirect url="walfadjri.jsp" />
    </c:when>
</c:choose>
```

- **Explication** : 
  - La balise `<c:choose>` permet de créer des conditions similaires à un `if-else`.
  - `<c:redirect>` effectue la redirection.

---

#### **Q6 (Utilisation de EL pour récupérer User-Agent)**  
Dans votre page JSP, utilisez :
```jsp
${header['User-Agent']}
```

- **Explication** : EL accède aux en-têtes HTTP via la notation `${header['nom_de_l_en_tete']}`.

---

#### **Q7 (Inclure `analytics.jsp` et accéder à la variable `nombreDeVisite`)**  
Dans `content.jsp`, utilisez :
```jsp
<%@ include file="analytics.jsp" %>
```

- **Explication** : La directive `<%@ include %>` inclut directement le contenu de la page spécifiée, ce qui rend la variable accessible.

---

#### **Q8 (Extraire le rôle de `idi2000` avec JSTL)**  
Ajoutez ce code dans votre page JSP :
```jsp
<c:set var="idi2000" value="1234:superuser:Idrissa-Sarr" />
<c:set var="userRole" value="${fn:substringAfter(fn:substringBefore(idi2000, ':Idrissa-Sarr'), ':')}" />
```

- **Explication** : 
  - La fonction JSTL `fn:substringBefore` extrait la partie avant `:Idrissa-Sarr`.
  - La fonction `fn:substringAfter` extrait la partie après `:` dans ce résultat.

---

#### **Q9 (Ajouter le menu de l’utilisateur avec EL)**  
Dans une page JSP, utilisez :
```jsp
<jsp:include page="menus.jsp">
    <jsp:param name="userRole" value="${param.userRole}" />
</jsp:include>
```

- **Explication** : L’action `<jsp:include>` inclut une page et transmet le paramètre `userRole` à la page incluse.

---

#### **Q10 (Afficher les jours un par ligne avec EL)**  
Déclarez les jours comme attribut de portée, puis utilisez :
```jsp
<c:forEach items="${jours}" var="jour">
    ${jour} <br />
</c:forEach>
```

- **Explication** : 
  - La balise JSTL `<c:forEach>` itère sur un tableau ou une collection.
  - EL accède à chaque élément via la variable définie (`jour`).
